# Miminet MCP

MCP-сервер для Codex, Claude Code, OpenCode и других клиентов с поддержкой stdio. Агент открывает редактор Miminet в Firefox, создаёт сеть в вашем аккаунте и возвращает ссылку на сохранённую схему. Вход, в том числе через Яндекс, вы выполняете в окне сайта.

## Проверить из браузера

**Автотесты.** Откройте [Test Miminet MCP в GitHub Actions](https://github.com/vlapugb/vibe-miminet-mcp/actions/workflows/test.yml). Выберите последний запуск или нажмите **Run workflow** на ветке `main`. Тесты запускают сервер через stdio, открывают редактор в Firefox и проверяют схемы на временной базе данных. Для этого достаточно аккаунта GitHub.

**Попробовать в своём аккаунте:**

1. [Создайте GitHub Codespace](https://codespaces.new/vlapugb/vibe-miminet-mcp) из ветки `main` и дождитесь установки Firefox и Python-пакетов.
2. В терминале Codespace выполните `.venv/bin/python demo.py`. Демонстрация создаст в вашем аккаунте одну сеть с названием **MCP demo**.
3. В нижней панели **Ports** откройте порт **6080 · Miminet Firefox** через значок глобуса и нажмите **Connect**. Оставьте видимость порта **Private**: это рабочий стол с вашей сессией Miminet. Если порт отсутствует в списке, нажмите **Forward a Port** и введите `6080`.
4. В открывшемся Firefox войдите на Miminet. Вернитесь в терминал и нажмите **Enter**. Через MCP демонстрация добавит коммутатор и два хоста, соединит их, задаст адреса `10.0.0.1/24` и `10.0.0.2/24`, заново откроет сеть и сверит данные. В терминале появятся **Verified two hosts** и ссылка. Её можно открыть и в обычном браузере под тем же аккаунтом.
5. Нажмите **Enter** ещё раз, чтобы закрыть демонстрацию. По окончании остановите Codespace через меню GitHub. Сеть останется в разделе **Мои сети**.

Вместо демонстрации можно подключить агента в том же Codespace. Для VS Code с поддержкой MCP откройте палитру команд, выберите **MCP: List Servers → miminet → Start** и разрешите запуск. Затем попросите агента открыть Miminet. Закройте демонстрацию перед запуском второго клиента, чтобы освободить профиль Firefox. [Конфигурация VS Code](.vscode/mcp.json) · [Порты Codespaces](https://docs.github.com/en/codespaces/developing-in-a-codespace/forwarding-ports-in-your-codespace)

## Подключить CLI

В Codespace окружение уже установлено. Для отдельного Linux-компьютера с рабочим столом выполните команды из корня клона с Python 3.12.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
PLAYWRIGHT_BROWSERS_PATH=0 .venv/bin/python -m playwright install --with-deps firefox
```

Из корня клона задайте два пути. Команду своего клиента можно выполнить из каталога проекта, в котором будете работать.

```sh
MCP_SCRIPT="$(pwd)/server.py"
MCP_PY="$(pwd)/.venv/bin/python"
```

| Клиент | Команда |
| --- | --- |
| Codex | `codex mcp add miminet -- "$MCP_PY" "$MCP_SCRIPT"` |
| Claude Code | `claude mcp add --transport stdio miminet -- "$MCP_PY" "$MCP_SCRIPT"` |
| OpenCode 2 | `opencode mcp add miminet -- "$MCP_PY" "$MCP_SCRIPT"` |

Для OpenCode 1.x добавьте в `opencode.json` запись с абсолютными путями. Другим stdio-клиентам передайте те же исполняемый файл и аргумент. На Windows путь к интерпретатору заканчивается на `.venv\Scripts\python.exe`.

```json
{
  "mcp": {
    "miminet": {
      "type": "local",
      "command": ["/path/to/vibe-miminet-mcp/.venv/bin/python", "/path/to/vibe-miminet-mcp/server.py"]
    }
  }
}
```

## Возможности

| Инструмент | Что делает |
| --- | --- |
| `open_miminet` | Открывает вход или список ваших сетей со ссылками. |
| `create_network` / `configure_network` | Создаёт сеть, меняет название, описание, масштаб и положение схемы. |
| `add_device` | Размещает любой элемент палитры: хост, специальный хост, маршрутизатор, коммутатор, концентратор, сервер или текстовое поле. |
| `configure_device` | Меняет имя, положение, шлюз или оформление текстового поля. |
| `connect_devices` | Соединяет два устройства. С `parallel: true` создаёт дополнительную физическую линию с отдельными портами. |
| `configure_link` | Настраивает проценты потери и дублирования пакетов. |
| `configure_interface` | Задаёт IPv4-адрес и префикс на подключённом порту. |
| `configure_switch` | Настраивает STP/RSTP, приоритет моста и VLAN на портах access/trunk. Пустой список портов отключает VLAN на коммутаторе. |
| `configure_vxlan` | Настраивает VNI клиентского порта или пары VNI/IP удалённых VTEP на сетевом порту маршрутизатора. Роль `off` очищает настройки этого порта. |
| `list_device_actions` | Показывает доступные на выбранном устройстве действия и обязательные параметры. |
| `set_device_action` | Добавляет или изменяет действие. Для последующего редактирования используйте идентификатор из ответа. |
| `remove_device_action` / `remove_element` | Удаляет действие, узел или линию. При удалении элемента ответ перечисляет затронутые связи и действия. |
| `get_network` | Заново читает сохранённые устройства, порты, линии, команды и настройки. |

Например, попросите агента создать два офиса с разными LAN, соединить маршрутизаторы GRE-туннелем и добавить встречные маршруты. IPIP и GRE задаются действием на каждом маршрутизаторе, VXLAN — настройкой порта. Для GRE назначьте физическому порту первого маршрутизатора `192.0.2.1/30`, второго — `192.0.2.2/30`. Параметры действия `gre` на первом конце:

```json
{"local_ip":"192.0.2.1","remote_ip":"192.0.2.2","tunnel_ip":"10.10.0.1","name":"gre1"}
```

На другом конце поменяйте местами физические адреса и укажите внутренний адрес `10.10.0.2`. Действия сохраняются в редакторе и применяются при запуске эмуляции. Также поддерживаются статические маршруты и ARP, proxy ARP, NAT, проброс портов, VLAN-сабинтерфейсы, DHCP, TCP/UDP и диагностика. Специальные команды имитации атак остаются в ручном редакторе. [Форма маршрутизатора](https://miminet.ru/config_router.html)

## Сессия и хранение

По умолчанию сервер открывает `https://miminet.ru`. Для своего экземпляра задайте `MIMINET_URL` с HTTPS-адресом или HTTP-адресом на loopback. Firefox хранит авторизацию в `~/.local/share/miminet-mcp/firefox`. Для второго одновременно работающего клиента задайте другой каталог в `MIMINET_PROFILE` и войдите в нём отдельно.

MCP использует штатные формы редактора, JWT и CSRF сайта. Исходники Miminet нужны только для интеграционного теста. Сайт по умолчанию включает просмотр новых сетей по ссылке. Редактор отправляет на сохранение полные списки узлов и связей, поэтому редактируйте одну сеть из одного окна. В другом браузере обновите вкладку для просмотра последних изменений. Если запись прервалась, сначала прочитайте схему. Изменение топологии может сбросить предыдущую эмуляцию. [Исходный проект Miminet](https://sourcecraft.dev/miminet/miminet)

## Тесты для разработчика

Две проверки охватывают валидацию действий и обнаружение инструментов через stdio. Для третьей нужен клон исходного Miminet и его зависимости. В CI используется версия `987515cdda6c60b994391a60814946cf1adba3ae`. Тест работает в headless Firefox с временной SQLite и выполняет также сценарий `demo.py`.

```sh
git clone https://git.sourcecraft.dev/miminet/miminet.git ../miminet-test-source
git -C ../miminet-test-source checkout --detach 987515cdda6c60b994391a60814946cf1adba3ae
export MIMINET_SOURCE="$(cd ../miminet-test-source && pwd)"
.venv/bin/python -m pip install uv
.venv/bin/uv pip install --python .venv/bin/python -r "$MIMINET_SOURCE/front/pyproject.toml" pytest
PLAYWRIGHT_BROWSERS_PATH=0 .venv/bin/python -m pytest -q test_server.py
```
